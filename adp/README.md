# ☠ ADP — Admin Deployment Panel

VPS server management panel berbasis web. Deploy, monitor, dan kelola aplikasi langsung dari browser (desktop & Android).

## Fitur

- **Process Manager** — start/stop/restart app via PM2
- **File Manager** — browse, upload, download, extract ZIP, rename
- **Code Editor** — Monaco Editor multi-tab dengan syntax highlight
- **Terminal** — xterm.js terminal langsung ke project directory
- **Database Manager** — buat isolated PostgreSQL/MariaDB per user
- **Monitoring** — CPU, RAM, disk, network real-time + history charts
- **User Management** — role-based (super_admin / admin / operator / user)
- **API Tokens** — Bearer token dengan scope granular
- **Audit Log** — semua aksi tercatat
- **2FA** — TOTP via Google Authenticator / Authy
- **Dark/Light mode** — mobile-first UI

## Instalasi

### Syarat
- Node.js 18+
- PostgreSQL **atau** MariaDB
- PM2 (auto-install oleh script)

### Install dari GitHub

```bash
git clone https://github.com/YOUR_USERNAME/adp.git
cd adp
bash scripts/install.sh
```

Script akan tanya semua konfigurasi di console — tidak perlu edit file apapun manual.

### Yang ditanya installer

| Pertanyaan | Default |
|---|---|
| Port | `3000` |
| Domain / CORS origin | `http://localhost:3000` |
| Projects root dir | `/opt/adp/projects` |
| Database engine | `postgresql` |
| DB host/port/name/user/pass | — |
| Admin username | `admin` |
| Admin email | `admin@localhost` |
| Admin password | — |

Setelah selesai buka `http://IP_VPS:3000` dan login.

## Update

```bash
git pull
bash scripts/install.sh   # build ulang & restart pm2
```

Atau rebuild manual:

```bash
npm run build
pm2 restart adp
```

## Commands PM2

```bash
pm2 status          # lihat status
pm2 logs adp        # lihat log
pm2 restart adp     # restart
pm2 stop adp        # stop
```


## Environment Variables

File `.env` dibuat otomatis oleh installer dan berisi kredensial rahasia. Jangan unggah atau bagikan file tersebut. Installer menampilkan ringkasan akun admin satu kali pada akhir proses; simpan secara privat sebelum menutup console.

---

> **Catatan keamanan:** Jangan expose port ADP ke internet tanpa HTTPS. Gunakan Nginx/Caddy sebagai reverse proxy dengan SSL.

## Catatan build pada VPS dengan heap Node.js terbatas

Installer menggunakan `NODE_OPTIONS=--max-old-space-size=640` saat build frontend untuk mengurangi risiko Vite kehabisan heap. Jika container VPS memiliki batas memori lebih rendah, sesuaikan nilainya dengan RAM yang tersedia. File `.env` lokal tidak disertakan dalam arsip distribusi.
